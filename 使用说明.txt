摄影产品信息一键发送工具

功能
1. 选择每日拍摄 Excel 表格。
2. 自动按“姓名/摄影师”分组。
3. 将对应“产品信息/sku”拼成企业微信消息。
4. 支持预览、复制当前摄影师消息、导出全部消息。
5. 配好企业微信自建应用 API 后，可以一键发送给摄影师本人。

表格要求
表头需包含这些字段：
- 日期
- 姓名 或 摄影师
- 产品信息/sku 或 sku 或 产品
- 总数/件 或 数量，可选

像截图里那种合并单元格导致下面行为空的格式也可以读取，程序会自动沿用上一行的日期、姓名和总数。

编码清单分配表
也支持类似 DOU2466-系列编码清单.xlsx 的格式：
1. 日期写在某一列，例如 E1 是“8.5日”。
2. 编码在日期左侧一列，例如 D 列。
3. 底部同一列写“人名+序号/范围”，例如：
   祝宜舜1～2
   陈灿3 39～41
4. 程序会默认读取最右侧的日期列，也就是最新那组日期，并按底部规则分发。

运行方式
用 Codex 自带 Python 运行：
C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe photographer_sender.py

更简单的启动方式
1. 双击“启动小程序.bat”可以直接打开小程序。
2. 双击“安装到桌面.bat”会在桌面创建“摄影产品信息一键发送工具.bat”。
3. 以后直接双击桌面的“摄影产品信息一键发送工具.bat”即可使用。

日期选择
1. 选择 Excel 后，程序会自动读取文件里的日期。
2. 默认选择最右侧的日期数据，例如同时有 8.4日 和 8.5日 时，会默认选 8.5日。
3. 如果要查看往期数据，可以在顶部“日期”下拉框里切换。

历史库和 SKU 筛选
1. 每次点“导入 Excel”，程序会把文件里的日期数据保存到 data/history.json。
2. 如果导入同一天日期，会用新文件内容更新这一天，不会影响其他日期。
3. 顶部“SKU筛选”可以输入完整或部分 SKU，例如输入 DO4436，会只显示包含这个 SKU 的联系人。
4. 点“清空筛选”恢复全部联系人。

共享给摄影师查看
1. 程序会自动启动实时共享页服务。
2. 你可以点小程序里的“打开实时共享页”，或双击“打开共享查看页.bat”。
3. 摄影师打开固定的局域网地址后，看到的就是最新数据。
4. 如果要给其他电脑看，把这台电脑的局域网地址发给摄影师，例如 http://你的IP:17865/share。
5. 以后你每天只需要在小程序里导入当天 Excel，旧日期会保留，摄影师打开同一个网页即可查看往日 SKU。

实时共享页使用方法
1. 先在这台电脑上启动小程序，或者直接双击“启动实时共享页.bat”。
2. 服务启动后，再把网页地址发给摄影师。
3. 只要这台电脑保持开着，摄影师每次打开都是最新内容。

共享页增强功能
1. 摄影师下拉框会记住上次选择的人名，摄影师下次打开会自动回到自己的数据。
2. 摄影师名字会按照拼音首字母 A 到 Z 排序。
3. 页面会按字母 A 到 Z 顺序排列摄影师名字。
4. 摄影师即使当天没有 SKU 也会显示出来，方便统一查看。
5. 每个摄影师卡片右上角有“复制全部 SKU”，可以一键复制当前筛选结果。
6. SKU 搜索会高亮匹配的编码片段。
7. 页面右上角会显示最后更新时间，方便确认是不是最新数据。

专业版功能
1. 页面有“摄影师查看 / 管理员”两种模式。
2. 管理员模式下，每位摄影师可以标记状态：待拍摄、已拍摄、需重拍、已完成。
3. 管理员模式下可以填写备注，例如“优先拍”“样衣未到”“需要重拍”。状态和备注保存在当前浏览器。
4. 每张卡片支持“复制 SKU”“复制完整消息”“复制个人链接”。
5. 复制个人链接后，发给摄影师打开会自动筛选到他本人。
6. 支持按 SKU 前缀筛选，例如 MRK、HUU、QUN。
7. 如果同一天 SKU 被分给多位摄影师，页面会显示重复 SKU 提醒。
8. 管理员模式会显示最近导入记录，包括导入时间、文件名、日期和 SKU 数。

企业微信 API 配置
1. 打开程序后点“编辑配置”，会生成 wecom_config.json。
2. 填入企业微信后台自建应用的 corp_id、agent_id、secret。
3. 在 user_map 里维护“表格姓名”到“企业微信 user_id”的对应关系。
4. 回到程序，选择 Excel，检查预览无误后点“API 一键发送”。

注意
企业微信桌面版坐标自动点击容易误发，不建议作为正式方案。这个工具优先走企业微信官方 API，发送对象由 user_id 精确匹配。
